# DiskManager 项目路线图

> 版本：1.0 | 更新日期：2026-06-09

## 1. 迭代总览

```
V1.0 ────────→ V1.1 ────────→ V1.2
MVP 核心        清理引擎        实时监控
可视化          智能建议        进阶功能
~2 周           ~2 周           ~2 周
```

每个版本约 2 周开发周期（按个人开发节奏，可调整）。

## 5. 未来规划（V2.0+）

| 方向 | 功能 | 说明 |

## 6. 开发节奏建议

### 每日开发流程

```
1. 选择当日任务（从当前版本任务列表中）
2. 编写代码
3. 本地测试
4. 提交 Git（每个功能一个 commit）
5. 更新进度
```

### 每周节奏

```
周一-周四：功能开发
周五：集成测试 + Bug 修复 + 文档更新
周末：可选 - 探索性开发或学习新技术
```

### 质量保证

- 每个功能完成后手动测试验收
- 关键路径写基本的单元测试
- 每个版本结束前做一次完整回归测试
- 保持 README 和文档同步更新
