# DiskManager 产品需求文档（PRD）

> 版本：1.0 | 更新日期：2026-06-09

---

## 1. 产品概述

### 1.1 产品定位

**DiskManager** 是一款本地运行的 Windows 磁盘空间管理工具，通过直观的可视化界面帮助用户快速定位磁盘空间占用问题，并提供智能清理建议。

### 1.2 一句话描述

> 用 TreeMap 让你的磁盘空间"一目了然"，智能建议帮你安全释放空间。

### 1.3 核心价值

| 价值维度 | 说明 |
|---------|------|
| **可视化** | 用 TreeMap 让目录大小关系直觉化，告别"不知道什么占了空间" |
| **智能建议** | 自动识别临时文件、缓存、重复文件、长期未访问文件，减少人工判断 |
| **安全可控** | 所有清理操作需用户确认，不做静默删除，可预览影响范围 |
| **实时感知** | 文件变化实时通知，磁盘使用趋势持续追踪 |

## 2. 目标用户

### 2.1 用户画像

| 阶段 | 用户类型 | 特征 | 需求 |
|------|---------|------|------|
| **V1.0** | 个人技术用户 | 熟悉电脑，有管理文件的习惯 | 快速扫描、可视化分析、定位大文件 |
| **V1.1** | 进阶用户 | 想清理但不确定哪些可以删 | 智能建议、重复文件检测、安全清理 |
| **V1.2** | 普通 Windows 用户 | 不太懂技术，电脑越来越卡 | 一键清理、傻瓜式操作、零门槛 |

### 2.2 典型使用场景

- **场景 1**：C 盘快满了，想知道什么占了空间
- **场景 2**：下载文件夹堆积了大量文件，想清理但不知从哪开始
- **场景 3**：系统运行变慢，怀疑是缓存/临时文件太多
- **场景 4**：多次备份导致大量重复文件，想找出并清理
- **场景 5**：想持续监控某个目录的空间变化趋势

## 3. 功能清单（MoSCoW 优先级）

### 3.1 Must Have — V1.0 MVP

| # | 功能 | 描述 | 验收标准 |
|---|------|------|----------|
| F01 | 磁盘分区总览 | 显示所有磁盘分区的总容量、已用、可用空间 | 环形进度条 + 数值显示 |
| F02 | 目录扫描 | 递归扫描指定目录，统计文件/文件夹大小 | 10 万文件 < 10 秒完成 |
| F03 | TreeMap 可视化 | 用矩形面积表示目录/文件大小占比 | 支持颜色区分文件类型 |
| F04 | 逐层下钻 | 点击 TreeMap 中的目录进入下一层 | 支持面包屑导航返回上级 |
| F05 | 大文件排行 | 列出 Top N 最大文件 | 支持排序、筛选、打开文件位置 |
| F06 | 按类型统计 | 按文件扩展名分组统计空间占用 | 饼图 + 列表展示 |
| F07 | Web 仪表盘 | 浏览器访问的本地 Web 界面 | 响应式布局，主流浏览器兼容 |
| F08 | 一键启动 | 一个命令启动后端服务并打开浏览器 | 启动后 3 秒内浏览器自动打开 |

### 3.2 Should Have — V1.1

| # | 功能 | 描述 | 验收标准 |
|---|------|------|----------|
| F09 | 临时文件检测 | 扫描系统临时目录、浏览器缓存等 | 列出路径 + 大小 + 清理理由 |
| F10 | 日志文件检测 | 检测 .log 文件和日志目录 | 按大小和时间排序 |
| F11 | 长期未访问文件 | 标记超过 N 天未访问的文件 | 用户可自定义阈值 |
| F12 | 重复文件检测 | 基于 MD5 哈希找出完全相同的文件 | 按大小预筛 + 哈希确认 |
| F13 | 清理建议卡片 | 以卡片形式展示每条清理建议 | 显示路径、大小、推荐理由、置信度 |
| F14 | 确认执行清理 | 用户逐条或批量确认后执行清理 | 执行前二次确认 + 删除到回收站 |
| F15 | 扫描历史 | 保存历史扫描记录，支持对比 | SQLite 持久化，列表展示 |

### 3.3 Could Have — V1.2

| # | 功能 | 描述 | 验收标准 |
|---|------|------|----------|
| F16 | 实时文件监控 | Watchdog 监听文件系统事件 | WebSocket 实时推送到前端 |
| F17 | 磁盘使用趋势 | 记录并展示磁盘使用量随时间变化 | 折线图，支持日/周/月视图 |
| F18 | 自定义扫描规则 | 排除目录、指定文件类型过滤 | 规则可保存、可复用 |
| F19 | 导出扫描报告 | 将扫描结果导出为 HTML 或 PDF | 包含图表和数据表格 |
| F20 | 系统托盘常驻 | 最小化到托盘，后台监控 | 托盘图标 + 右键菜单 |

### 3.4 Won't Have（暂不实现）

- 跨平台支持（macOS / Linux）
- 网络存储 / NAS 管理
- 云同步功能
- 移动端 App
- 文件加密 / 隐私保护

## 4. 用户故事（User Stories）

### V1.0 核心故事

```
US-01: 作为用户，我希望看到电脑所有磁盘分区的使用情况，
       以便快速了解哪些磁盘空间紧张。

US-02: 作为用户，我希望能选择一个目录进行扫描，
       以便了解该目录下各文件和子目录的空间占用。

US-03: 作为用户，我希望看到扫描结果的 TreeMap 可视化，
       以便直觉地判断哪些目录/文件最占空间。

US-04: 作为用户，我希望能点击 TreeMap 中的目录进入下一层，
       以便逐层深入排查空间占用来源。

US-05: 作为用户，我希望看到最大的 N 个文件列表，
       以便快速定位可以删除或移动的大文件。

US-06: 作为用户，我希望按文件类型看到空间占用分布，
       以便了解是视频、图片还是其他类型占了大头。

US-07: 作为用户，我希望能一键启动工具并在浏览器中使用，
       以便不需要复杂的安装和配置。
```

### V1.1 扩展故事

```
US-08: 作为用户，我希望工具能自动检测可清理的临时文件，
       以便不需要手动去各个目录找。

US-09: 作为用户，我希望看到清理建议时附带理由说明，
       以便判断是否真的可以删除。

US-10: 作为用户，我希望在执行清理前能预览将删除的内容，
       以便避免误删重要文件。

US-11: 作为用户，我希望找到完全重复的文件并选择保留哪个，
       以便释放被重复占用的空间。

US-12: 作为用户，我希望看到以前的扫描记录，
       以便对比磁盘空间的变化趋势。
```

## 5. 非功能性需求

| 维度 | 要求 | 指标 |
|------|------|------|
| **性能** | 大目录扫描速度 | 10 万文件 < 10 秒 |
| **性能** | API 响应时间 | P95 < 500ms |
| **性能** | 前端首屏加载 | < 2 秒 |
| **内存** | 扫描过程中内存占用 | < 500MB（百万文件级别） |
| **兼容性** | 浏览器支持 | Chrome 90+, Edge 90+, Firefox 90+ |
| **兼容性** | Windows 版本 | Windows 10/11 |
| **可靠性** | 扫描过程可中断 | 支持取消正在进行的扫描 |
| **可靠性** | 异常容错 | 文件权限不足时跳过，不中断整体扫描 |
| **安全性** | 删除操作安全 | 默认删除到回收站，非物理删除 |
| **可用性** | 启动门槛 | 一条命令启动，无需额外配置 |

## 7. 验收场景（Acceptance Scenarios）

### 场景 1：首次使用扫描 C 盘用户目录

```
Given 用户首次启动 DiskManager
When  选择 "C:\Users\当前用户" 并点击扫描
Then  10 秒内完成扫描
And   显示目录 TreeMap，面积最大的目录排在左上角
And   右侧显示文件类型分布饼图
```

### 场景 2：下钻定位大文件

``Given 用户查看扫描结果的 TreeMap
When  点击 "Documents" 目录块
Then  TreeMap 刷新为 Documents 子目录的内容
And   面包屑显示 "C:\Users\用户 > Documents"
And   可点击面包屑返回上一级
``

### 场景 3：查看清理建议并执行

```
Given 用户查看扫描结果的清理建议页
When  系统检测到 2.3GB 临时文件和 800MB 缓存
Then  显示建议卡片，每条包含：文件路径、大小、清理理由
When  用户勾选并点击 "确认清理"
Then  弹出二次确认对话框
When  用户确认
Then  文件移动到回收站，并显示释放的空间大小
```

## 8. 术语表

| 术语 | 定义 |
|------|------|
| TreeMap | 矩形树图，用矩形面积表示层级数据的大小关系 |
| 下钻（Drill-down） | 从高层级视图进入低层级细节视图的操作 |
| 哈希（Hash） | 文件内容的唯一摘要值，用于判断文件是否完全相同 |
| 回收站 | Windows 系统的临时删除存储，可恢复 |
| 扫描快照 | 某次扫描的时间点完整数据记录 |
