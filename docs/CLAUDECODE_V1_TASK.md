## 1. 目标

请实现 DiskManager 的 V1.0 MVP，让用户可以在 Windows 本机完成：

```
启动应用 -> 查看磁盘分区 -> 选择目录扫描 -> 查看 TreeMap -> 逐层下钻 -> 查看大文件排行和类型统计 -> 打开文件位置
```

产品体验可以参考 SpaceSniffer，重点是直观、快速、可探索。

---

## 2. 技术约束

优先遵循仓库已有文档：

- `docs/PRD.md`
- `docs/ARCHITECTURE.md`
- `docs/API.md`
- `docs/DATABASE.md`

- Python 3.11+

## 3. 必须实现的能力

### 3.1 一键启动

完成：

- `requirements.txt`
- `start.py`
- 后端默认监听 `127.0.0.1:8765`
- 启动后可打开浏览器访问首页

验收：

```bash
pip install -r requirements.txt
python start.py
```

浏览器可访问：

```text
http://127.0.0.1:8765
```

### 3.2 磁盘分区总览

完成：

- 返回本机磁盘分区列表
- 展示盘符、总容量、已用、可用、使用率、文件系统

验收：

- `GET /api/disks` 可用
- 首页可以看到磁盘卡片

### 3.3 目录扫描

完成：

- 支持扫描用户输入的本机目录
- 统计文件大小、目录总大小、文件数量、目录数量
- 扫描过程不中断 UI
- 权限不足、路径过长等错误被记录并跳过
- 支持查询扫描状态

验收：

- `POST /api/scan` 可创建任务
- `GET /api/scan/{id}` 可查状态
- 扫描完成后能得到总大小、文件数、目录数、错误数

### 3.4 TreeMap 可视化

完成：

- 使用 ECharts TreeMap 展示扫描结果
- 默认展示当前目录下 Top 50 大项
- 超出部分合并为“其他”
- 目录和文件应可区分
- 文件类型尽量用颜色区分

验收：

- 扫描完成后自动进入结果视图
- TreeMap 面积与文件或目录大小相关
- 悬停可看到名称、大小、占比

### 3.5 下钻和面包屑

完成：

- 点击 TreeMap 中的目录进入该目录
- 面包屑显示当前路径
- 点击面包屑可返回上级

验收：

- 至少能完成 3 层目录下钻和返回
- 不刷新整个应用也能更新视图

### 3.6 大文件排行

完成：

- 展示 Top N 大文件
- 支持按大小排序
- 支持打开文件所在位置

验收：

- `GET /api/scan/{id}/files/top` 可用
- 前端可查看大文件列表
- 点击“打开位置”能调用 Windows 资源管理器

### 3.7 文件类型统计

完成：

- 按扩展名统计文件数量和总大小
- 前端展示图表和列表

验收：

- `GET /api/scan/{id}/files/types` 可用
- 前端能看到类型占比

## 4. 暂不实现

本轮不要实现：

- 删除文件
- 移动到回收站
- 清理建议
- 重复文件哈希检测
- 实时监控
- WebSocket
- 系统托盘
- 报告导出

如需预留接口可以预留，但不要扩大实现范围。

---

## 5. 体验要求

- 打开首页就是工具界面，不做营销落地页。
- 暗色主题，信息密度高，参考 SpaceSniffer 的探索感。
- TreeMap 是核心视觉区域。
- 扫描中必须有明确状态，不能让用户以为卡住。
- 错误提示要能被普通用户理解。
- 所有按钮、输入框、表格在常见桌面宽度下不能重叠。

---

## 6. 自测清单

开发完成后，请至少完成以下自测：

- 启动服务成功。
- 首页能打开。
- `GET /api/disks` 返回真实分区。
- 扫描项目目录成功。
- 扫描一个用户目录或测试目录成功。
- TreeMap 正常渲染。
- 下钻和面包屑可用。
- 大文件排行可用。
- 类型统计可用。
- 打开文件位置可用。
- 权限错误不会导致扫描崩溃。
