# DiskManager 前端 UI 设计文档

> 版本：1.0 | 更新日期：2026-06-09

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **信息密度优先** | 磁盘管理工具需要展示大量数据，优先信息密度而非留白 |
| **渐进式展示** | 先概览再细节，支持逐层下钻，不一次性铺开所有信息 |
| **操作可逆** | 所有破坏性操作（删除）需二次确认，支持撤销 |
| **响应迅速** | 数据加载有骨架屏/进度条，不让用户等待时产生焦虑 |
| **暗色主题** | 深色背景 + 高对比数据，适合长时间使用 |
